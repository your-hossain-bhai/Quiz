# 📚 Quiz App

A modern and interactive Quiz Application built with **Flutter**, designed to provide an engaging learning experience through category-based quizzes, instant scoring, and a clean user interface.

## ✨ Features

- 🔐 User Authentication (Login & Signup)
- 🏠 Beautiful Home Screen
- 📂 Category-based Quizzes
- ❓ Multiple Choice Questions (MCQ)
- 📊 Real-time Quiz Progress
- 🏆 Instant Result & Score Calculation
- 📈 Accuracy Percentage
- 👤 User Profile
- 🥇 Leaderboard
- 📱 Responsive UI
- 🎨 Modern Material Design


## 🛠️ Built With

- **Flutter**
- **Dart**
- Material Design
- Provider (State Management)
- REST API / Local JSON *(Depending on your project)*

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio / VS Code
- Android Emulator or Physical Device

### Installation

Clone the repository

```bash
git clone https://github.com/yourusername/quiz_app.git
```

Navigate to the project

```bash
cd quiz_app
```

Install dependencies

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
